LINEで届く あなたの秘書はじめての方へ

設定サイトへ

この案内のとおりに上から進めると、毎日決まった時刻に、あなた専用の秘書から今日（または明日）の予定とタスクがLINEで届くようになります。

用意するもの

  • Googleアカウント（Gmailのアカウント）
    Googleアカウントがない方はこちら（作り方）
  • LINE（いつも使っているLINEで大丈夫です）
  • パソコン：この案内はパソコンで進める手順で書いています
    パソコンがない方も、サポートできますので、担当にご連絡ください。
  • 購入後に届いた利用者IDと初期パスワード（購入時に登録したメールアドレスに届きます）

全体の流れ

  1. 秘書用のLINE公式アカウントを作る
  2. Messaging API（メッセージを自動で送る仕組み）を使えるようにする
  3. スプレッドシートのひな形をコピーして、動くようにする
  4. 設定サイトにログインして、スプレッドシートとつなぐ
  5. LINEとつなぐ
  6. 「はじめにやること」の項目を順番に進める

英語の画面が出てくるところは、英語の文字と、その意味をいっしょに書いています。

1秘書用のLINE公式アカウントを作る

あなたにLINEを送ってくれる「秘書」を、LINE公式アカウントとして新しく作ります。無料のプランで使います。

LINE公式アカウントを作る画面を開く
  1. 「LINE公式アカウントを開設する」を選び、LINEアカウントで登録（いつものLINEでログイン）します。
  2. 作成の入力画面で、次のように選びます。
    アカウント名例：「あなたの秘書」「〇〇の秘書」（あとで変えられます）
    業種ウェブサービス → その他
    運用目的その他
    主な使い方メッセージ配信
  3. 「ビジネスマネージャーの組織との接続」という項目が出ることがあります。分かりにくいですが、つながなくて大丈夫です。
  4. 「認証済アカウント」の申請は、「後で」で大丈夫です（審査は必要ありません）。
  5. 情報の利用についての同意が2つ続けて出ます。内容を確かめて、どちらも同意して進みます。
  6. 作り終わると、あなたのLINEに、作った公式アカウントが自動で友だち追加されます。これで正しい状態です。
  7. 「運用を始める前に」という画面の2ページ目は、ホーム画面へ進んで大丈夫です。
1つのアカウントで作れる公式アカウントは、最大100個までです。この秘書のために1つ作っても、ほかの公式アカウントには影響しません。

2Messaging APIを使えるようにする

スプレッドシートから秘書にメッセージを送らせるための設定です。手順1で作った公式アカウントの管理画面で行います。

公式アカウントの管理画面を開く
  1. 作った公式アカウントを選び、右上の「設定」→ 左の「Messaging API」→「Messaging APIを利用する」を押します。
  2. 「LINE Developersに登録する開発者情報」が出たら、あなたの名前と、ふだん見ているメールアドレスを入れます（LINEからのお知らせが届くアドレスです）。
  3. プロバイダーを作ります。プロバイダー名は あなたの秘書 にしてください。
    プロバイダー名を入れる画面が2回出てくるように見えることがありますが、同じ名前（あなたの秘書）で大丈夫です。
  4. プライバシーポリシーと利用規約のURLは、入れなくて大丈夫です（任意）。
  5. 「Webhook URL」などの項目は、さわらなくて大丈夫です。

3スプレッドシートのひな形をコピーして、動くようにする

予定やタスクを入れておく、あなた専用のスプレッドシートを用意します。秘書を動かすプログラムも、いっしょにコピーされます。

ひな形をコピーする

3-1　コピーを作る

  1. 上のボタンを押し、出てきた画面で「コピーを作成」を押します。
  2. あなたのGoogleドライブに、スプレッドシートのコピーができて開きます。このコピーが、これからあなたが使うものです。

3-2　はじめの準備を動かす（1回だけ）

  1. コピーしたスプレッドシートの上のメニューで、「拡張機能」→「Apps Script」を開きます。
  2. 上の関数の選び方の欄で「初期設定」を選び、「▷ 実行」を押します。
  3. 「承認が必要です」と出たら「権限を確認」を押し、ご自分のGoogleアカウントを選びます。
  4. 「このアプリは Google で確認されていません」と出たら、「詳細」→ いちばん下の「LINE秘書（安全ではないページ）に移動」を押します。
    これは、ご自分で使うために作ったプログラムに出る表示です。許可の画面にはGoogleカレンダーの項目も出てきますが、このプログラムがカレンダーでするのは、予定を読むことだけです。
  5. 許可の画面で「すべて選択」にチェックを入れて、「続行」を押します。
  6. 下の「実行ログ」に「初期設定が終わりました」と出れば完了です。

3-3　デプロイする（設定サイトとつなぐための準備・1回だけ）

  1. 右上の「デプロイ」→「新しいデプロイ」を押します。
  2. 「種類の選択」の横の歯車を押して、「ウェブアプリ」を選びます。
  3. 次のように選びます。
    説明空のままで大丈夫です
    次のユーザーとして実行自分
    アクセスできるユーザー全員
    「全員」にしても、あなたのパスワードを知らない人は中身を見られません。設定サイトからつなぐために必要な設定です。
  4. 「デプロイ」を押します。
  5. 「ウェブアプリ」のURLの下の「コピー」を押します。このURLを、すぐ次の手順4で使います。

4設定サイトにログインして、スプレッドシートとつなぐ

設定サイトを開く
  1. 購入後に届いた利用者IDと初期パスワードで、「ログイン」します。
  2. はじめてのときは、あなた自身のパスワードに変えます（8文字以上）。新しいパスワードを2回入れて「パスワードを変える」を押します。
  3. スプレッドシートとつなぐ画面で、手順3-3でコピーしたURLを貼り、「つなぐ」を押します。
    貼るのは「https://script.google.com/macros/s/…/exec」の形のURLです。スプレッドシートの画面のURL（docs.google.com…）ではありません。

つなぐと、設定サイトのホームの「はじめにやること」に、残りのやることが順番に出てきます。

5LINEとつなぐ

設定サイトのホームの「はじめにやること」で「LINEとつなぐ」を押すと、LINEの情報を入れる欄が開きます。入れる値は、LINE Developers（開発者用の画面）からコピーします。

LINE Developersを開く
コピーと貼り付けは、1つずつ行ってください。2つ続けてコピーすると、先にコピーしたものが消えてしまいます。必ず「1つコピー → すぐ貼って保存 → 次をコピー」の順に進めます。
  1. LINE Developersで、プロバイダー「あなたの秘書」→ 手順1で作った公式アカウントのチャネルを開きます。
  2. チャネルアクセストークン（長期）
    1. Messaging API（Messaging API設定）タブを開き、いちばん下までスクロールします。
    2. 「チャネルアクセストークン（長期）」のIssue（＝発行）を押すと、長い文字が出ます。それをコピーします。
    3. すぐに設定サイトの「チャネルアクセストークン（長期）」の欄に貼り、「LINEの情報を保存」を押します。
  3. あなたのユーザーID
    1. Basic settings（＝チャネル基本設定）タブを開き、いちばん下までスクロールします。
    2. Your user ID（＝あなたのユーザーID）の、「U」から始まる文字をコピーします。
    3. 設定サイトの「あなたのユーザーID」の欄に貼り、「LINEの情報を保存」を押します。

入れた値は、あなたのスプレッドシートのプログラムの中にだけ保存されます。

6「はじめにやること」の項目を順番に進める

あとは、設定サイトのホームにある「はじめにやること」の項目を、順番に進めるだけです。

  1. 毎日のリマインドの時刻を決める：毎日何時に届けるかを決めます。夜に明日の予定を受け取りたいときは「翌日の予定を送る」にチェックします。
  2. 予定やタスクを入れる：「定例」（毎週月曜・隔週・毎月第3土曜など）、「単発」（急な予定・会議）、「タスク」を入れます。
  3. LINE送信確認：ちゃんと届くかを確かめます。押す前に確認が出ます。

Googleカレンダーの予定も入れたいときは、⚙設定 →「全体の設定」→「Googleカレンダーの連携」で、入れたいカレンダーにチェックを入れて保存します。

よくある質問

別のスマホやパソコンからも使えますか？

使えます。設定サイトを開いて、同じ利用者IDとパスワードでログインしてください。

うまくいかないときは？

どの手順で、どんな画面や文字が出たかを、担当に知らせてください。画面の写真（スクリーンショット）があると早く分かります。設定サイトの「お問い合わせ」から、画面の写真をつけて送れます。
